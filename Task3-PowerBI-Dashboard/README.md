# SWYNEX Internship – Task 3: Interactive Power BI Dashboard

## Project Overview

This project focuses on building an interactive Sales Performance Dashboard using Power BI as part of the SWYNEX Internship – Task 3.

The dashboard presents key business metrics, sales trends, category-wise performance, city-wise revenue, and payment mode analysis.

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- CSV Dataset

## Dashboard Features

- KPI Cards: Total Revenue, Total Orders, Total Quantity, and Average Order Value.
- Monthly Revenue Trend.
- Category-wise Revenue Analysis.
- City-wise Revenue Analysis.
- Payment Mode Analysis.
- Quantity Analysis.
- Interactive filters and slicers.

## Dataset

The dashboard uses the cleaned sales dataset generated in Task 1 and analyzed in Task 2.

## Key Objectives

- Monitor overall sales performance.
- Identify top-performing product categories and cities.
- Analyze monthly revenue trends.
- Understand customer payment preferences.
- Support data-driven business decisions.

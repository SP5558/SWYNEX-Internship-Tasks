## 🚀 Tasks Overview

### Task 1: Data Cleaning and Preparation

- Loaded and explored the raw sales dataset.
- Identified and removed duplicate records.
- Handled missing and inconsistent values.
- Performed data validation and cleaning.
- Exported the cleaned dataset for further analysis.

**Dataset Summary:**
- Original Records: 3,060
- Duplicate Records Removed: 60
- Final Cleaned Records: 3,000

### Task 2: Exploratory Data Analysis (EDA)

- Analyzed the cleaned sales dataset using Python.
- Explored sales across categories and cities.
- Analyzed monthly sales trends.
- Examined payment mode distribution.
- Investigated quantity patterns and potential outliers.
- Created visualizations using Matplotlib.
- Prepared an EDA report with key findings.
